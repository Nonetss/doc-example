## Without a menu

Without `menu.yaml`, the sidebar is the folders of `docs/`: each folder is a section, ordered by the `orden` of its `index.mdx` and then by title, and the catalog comes last. It works, but grouping pages differently means moving files, and moving a file changes its URL.

## With a menu

`menu.yaml` lists the sidebar's groups, in order. Each group has a title, an icon, a description and its entries:

```yaml
secciones:
  - titulo: Infrastructure
    icono: server
    descripcion: The machines and the network
    paginas:
      - network                                   # a folder, with all its pages
      - { ruta: containers/komodo, icono: layers } # with its own title or icon
      - backups/duplicati/create-backup             # a single page
  - titulo: Data
    icono: database
    paginas: [catalogo]                           # the catalog; or catalogo/machines
```

| Key | What it is |
| --- | --- |
| `secciones` | The groups, at least one. |
| `titulo` | Required. The group's title in the sidebar. |
| `icono` | Optional. A Lucide icon name. |
| `descripcion` | Optional. One sentence on what the group holds. |
| `paginas` | Required. Its entries: a path, or `ruta` with an optional `titulo` and `icono`. |

An entry names a page (`network/dns`), a folder of `docs/` (`network`, which brings all its pages in their usual order), the catalog (`catalogo`) or one catalog type (`catalogo/machines`). **Folders store the pages; the menu decides where they show.** A group can gather folders from anywhere, and every page keeps its URL.

This site's own menu is a good example: look at its `menu.yaml`.

## The menu wins

What the menu says about an entry is what every view shows: the sidebar, the page header, the breadcrumbs, the cards, the search and `llms.txt`. A page header only counts for what the menu leaves out.

- `{ ruta: network, icono: network }` gives the section its icon; the `icono` of `docs/network/index.mdx` is then ignored.
- When the header says something else, the page is reported ("la cabecera dice…, pero manda menu.yaml"), so nobody edits a value that never shows.
- Breadcrumbs start with the group, as plain text: a group is a heading, not a page.

## What gets reported

- An entry that names nothing, the home, or something an earlier entry already shows (the same path, a folder holding it, or a page inside it): reported and skipped. The rest of the menu is used.
- A page or catalog type that no entry shows: listed in a last group, **"Otros"**, and reported on the page. Nothing written is lost from the sidebar.
- A badly formed `menu.yaml` (an unknown key, a missing title, an icon Lucide does not have): it is a declaration, so the platform keeps the last valid version until it is fixed.

The problems of `menu.yaml` show to admins on the repository's home.
