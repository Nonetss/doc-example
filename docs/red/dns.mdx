## Qué es

[AdGuard Home](catalogo:servicios/adguard) es el DNS de toda la red de casa. Resuelve los nombres internos (`*.casa.example`) y reenvía el resto a Quad9 quitando la publicidad y el rastreo.

## Configuración actual

- Corre en el stack [docker-01-adguard](catalogo:stacks/docker-01-adguard), en [docker-01](catalogo:maquinas/docker-01).
- Los nombres internos son reescrituras de DNS: cada `servicio.casa.example` apunta a `192.168.1.20`.

## Observaciones

<Aviso tipo="peligro">
Si se cae docker-01, se cae el DNS de toda la casa. No hay un segundo DNS.
</Aviso>
