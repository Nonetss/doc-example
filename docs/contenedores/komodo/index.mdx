[Komodo](catalogo:servicios/komodo) guarda el compose de cada stack y los despliega en los servidores a través de su agente, Periphery.

## ¿Dónde busco…?

| Quiero… | Ficha |
| --- | --- |
| Levantar un servicio nuevo | [Nuevo stack](nuevo-stack.mdx) |
| Ver qué contenedores hay en cada servidor | [Stacks](catalogo:stacks) |

## Cómo encaja todo

```diagrama
direccion: derecha
nodos:
  komodo: { entidad: servicios/komodo }
  periphery: { nombre: Periphery, sub: agente en cada servidor }
  stacks: { nombre: Stacks, sub: docker compose, tipo: almacen }
flechas:
  - komodo -> periphery: deploy
  - periphery -> stacks: docker compose up
```
