The platform does not hold any documentation itself: it reads it from a **content repository**, a git repository with pages in MDX and data in YAML. This site is one of them, and it explains how to write one. Everything it describes it also uses, so its own files are the examples: its [menu](repository/menu.mdx) is a `menu.yaml`, its [reference tables](catalogo:files) come from its catalog and the diagrams below are files under `diagramas/`.

If this is your first time, start with [Getting started](getting-started.mdx).
