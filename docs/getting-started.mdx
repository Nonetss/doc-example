1. **The network**: how the home names resolve and how you get in from outside. Start with [DNS](network/dns.mdx).
2. **The containers**: almost everything runs on [docker-01](catalogo:machines/docker-01) and is managed with [Komodo](containers/komodo/index.mdx).
3. **The backups**: what is backed up, where, and how to restore it, in [Duplicati](backups/duplicati/index.mdx).

<Callout type="info">
Credentials are not in the documentation: they live in the platform's vault. Pages say which connection to use, never the password.
</Callout>
